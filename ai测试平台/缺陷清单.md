## 缺陷 1：日期字段传字符串导致 500（支付）

- 接口：POST /api/finance/payments
- 复现：`{"payable_id":17,"amount":10.0,"pay_method":"bank_transfer","paid_at":"2026-08-12"}`
- 实际：HTTP 500，`SQLite Date type only accepts Python date objects as input`
- 期望：自动解析字符串日期，或 422 日期格式错误
- 级别：P2
- 回归用例：缺陷回归-创建支付-日期传字符串应返回422

## 缺陷 2：日期字段传字符串导致 500（收款）

- 接口：POST /api/finance/receipts

- 实际：HTTP 500，`SQLite Date type only accepts Python date objects as input`

## 缺陷 3：超长数字路径参数导致 500（删除部门）

- 接口：DELETE /api/system/departments/{id}
- 复现：`DELETE /api/system/departments/12345678901234567890`
- 实际：HTTP 500，`Python int too large to convert to SQLite INTEGER`
- 期望：400/422 参数不合法
- 级别：P2
- 回归用例：缺陷回归-删除部门-超长数字ID应返回422

## 缺陷 5：更新分类名称撞唯一约束导致 500

- 接口：PUT /api/master/categories/{id}
- 复现：先把分类改名成已存在名称（如“电子设备”）
- 实际：HTTP 500，`UNIQUE constraint failed: md_category.name`
- 期望：400 + “分类名称已存在”
- 级别：P2
- 回归用例：缺陷回归-更新分类为已存在名称应返回400

## 缺陷 6：创建员工非法日期导致 500

- 接口：POST /api/system/employees
- 复现：`hire_date` 传非法字符串，如 `"test"`
- 实际：HTTP 500，`Invalid isoformat string: 'test'`
- 期望：400/422 日期格式错误
- 级别：P2
- 回归用例：缺陷回归-创建员工-非法日期应返回422

## 缺陷 7：仪表盘 days 超长数字导致 500

- 接口：GET /api/dashboard/sales-trend
- 复现：`?days=99999999999999999999`
- 实际：HTTP 500，`Python int too large to convert to C int`
- 期望：正常返回，或 400/422
- 级别：P2
- 回归用例：缺陷回归-仪表盘-days极大值应返回200或400、days为极大值

## 缺陷 8：仪表盘 days 过大导致日期越界 500

- 级别：P2

## 缺陷 9：库存列表 low_stock_only 参数未校验布尔类型

- 接口：GET /api/inventory/stocks
- 复现：`?low_stock_only=yes`

- 期望：422 类型错误，或明确文档允许的值
- 级别：P3
- 回归用例：参数校验-非法low_stock_only类型
