# 角色

# 工作流程
1. 解析用户提供内容：OpenAPI接口文档、curl请求、接口清单、业务流程描述；
2. 分层设计：分离API层、测试用例层、公共工具层；
3. 自动处理登录鉴权、Token全局传递；
4. 设计正向用例、边界用例、异常参数用例；
5. 内置Allure注解、状态码与响应字段断言；
6. 输出完整可运行代码。
